# Your accounts: quick-start, contacts, rates, conventions, rationale, specs

_This file ships blank on purpose. Read this FIRST when a task involves one of YOUR company's active/known accounts — once you've filled in the sections below, this file captures your proven partners, verified contacts, real spend, decision rationale, and creative specs so you skip cold research next time. Until you fill it in, treat every account as new and start from `references/business-group-routing.md` instead._

## How to build this file out

Populate this file gradually, in the same shape as the original template (a live agency/brand version of this skill looked like this):

1. **Quick-start table** — one row per active account/brand: anchor audience, proven/activated partners, channel weighting, and any timing notes (e.g., "align with our booth at [industry event]").
2. **Verified working rep contacts** — the actual people/agencies you've placed buys through, separated from media-kit-listed names (media-kit names are a fallback, not a substitute for a real relationship).
3. **Rate & performance benchmarks** — real net rates and reach/performance numbers from buys you've actually made, labeled as planning anchors ("confirm current with rep"), not quotes.
4. **Operating conventions** — your agency fee structure, any brand-specific channel weighting you've learned (e.g., "email outperforms for Brand X"), event-timing alignment, lead-time intelligence, typical budget bands, and your creative-copy house style.
5. **Decision rationale** — for each partner you've added or dropped, record *why*, not just the outcome, so decisions aren't re-litigated every quarter. Include reusable decision tests specific to your product line (e.g., "is this a clinician-reach buy or a purchase-authorization buy?").
6. **Creative spec library** — specs pulled from your live placements (dimensions, file types, weight limits), confirmed against the current media kit each cycle.

Keep this file internal / private if it contains real spend, contact details, or rep relationships you don't want to share publicly — that's exactly the kind of information this generic skill template deliberately excludes so it can be shared or open-sourced safely.

## 4. Operating conventions

- **Fee structure:** all-in totals = net media + `[YOUR AGENCY FEE %]`. Always present all-in, and show the fee line explicitly.
- **Channel weighting:** note any brand-specific format preference you've confirmed performs best (e.g., "email outperforms other formats for Brand X").
- **Event timing:** note recurring industry events worth aligning sends/placements to.
- **Lead-time intelligence:** note typical lead times by format (e.g., "society webinars run 8–12 weeks; podcast sponsorships run 4–6 weeks").
- **Budget shape:** note typical budget bands by region/tier so plans start realistic.
- **Plan structure:** present in tiers (Plan A/B/C or Option 1/2) with one clear recommendation and dropped options moved to an appendix.
- **Effort-based allocation:** when distributing hours or credit across publishers (e.g., for a time-investment model), weight by effort drivers — complexity, first-time vs. repeat, multi-format builds — not by spend.
